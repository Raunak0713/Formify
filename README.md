# Formify ✨

**Formify** is a powerful and customizable form builder built with **Next.js**, **Convex**, **TypeScript**, and **Clerk**. It allows users to create forms with multiple question types (text, MCQ, file upload) and collect responses seamlessly. We focus on offering **buttery-smooth** animations and a clean UI/UX experience.

## 💻 **Tech Stack**

- **Next.js** – Full-stack React framework
- **Convex** – For fast and real-time database management
- **Clerk** – User authentication and management
- **TypeScript** – Ensures strong typing for all data
- **Framer Motion** – For buttery-smooth animations
- **Tailwind CSS** – Customizable utility-first CSS
- **ShadCN UI** – Pre-built components for fast UI creation
